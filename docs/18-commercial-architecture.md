## 一、设计理念

### 1.1 核心原则

LifeOS 的商业化不是"卖聊天次数"，而是**建立一个数字生命经济系统**。

```
真实货币（RMB/USD）
        ↓
    Life Coin（付费货币）
        ↓
    消费（礼物 / 外观 / 能力 / Marketplace）
        ↓
    创作者收益分成
        ↓
    经济循环
```

### 1.2 商业化目标

| 目标 | 说明 |
|------|------|
| **用户体验** | 免费用户也能享受核心体验，付费提升而非付费解锁 |
| **创作者经济** | 创作者可以通过 Marketplace 获得收益 |
| **经济循环** | 货币在平台内流转，形成正向循环 |
| **可持续** | 平台收入覆盖运营成本，持续投入研发 |

## 二、商业模式 — 混合模式

### 2.1 收入来源

```
收入来源
├── 会员订阅（Pro / Creator）
│   └── 月度/年度订阅费
├── 虚拟货币消费（Life Coin）
│   ├── 礼物打赏
│   ├── 外观购买
│   ├── 能力解锁
│   └── 高级功能
├── Marketplace 交易
│   ├── 数字生命模板
│   ├── 插件
│   ├── 外观资源
│   └── 平台分成（30%）
└── 增值服务（未来）
    ├── API 调用
    ├── 企业版
    └── 广告（可选）
```

### 2.2 用户分层

| 层级 | 价格 | 核心权益 | 限制 |
|------|------|---------|------|
| **Free** | 免费 | 体验数字生命、基础模型、基础记忆 | 每日互动次数限制、记忆容量限制 |
| **Pro** | ¥30/月 或 ¥288/年 | 无限互动、高级模型、长期记忆、情绪成长、高级外观 | 无互动限制 |
| **Creator** | ¥100/月 或 ¥888/年 | Pro 全部权益 + 创建数字生命 + 发布 Marketplace + 收益分成 | 需创作者认证 |

### 2.3 Free 层限制策略

```
Free 用户限制：
├── 每日互动次数：50 条消息/天
├── AI 模型：基础模型（GPT-3.5 级别）
├── 记忆容量：最近 7 天
├── 情绪系统：基础情绪（无长期情绪成长）
├── 外观：默认外观（无自定义）
└── 数字生命数量：1 个

Pro 用户解锁：
├── 无限互动
├── 高级模型（GPT-4 级别）
├── 长期记忆（无限容量）
├── 情绪成长（完整情绪系统）
├── 高级外观（自定义 Live2D/VRM）
└── 数字生命数量：3 个

Creator 用户解锁：
├── Pro 全部权益
├── 数字生命数量：无限制
├── Marketplace 发布权
├── 创作者工具
└── 收益分成（70% 创作者 / 30% 平台）
```

## 三、虚拟经济体系

### 3.1 双系统设计

```
┌─────────────────────────────────┐
│         真实货币（RMB/USD）       │
│              ↓ 充值               │
│      Life Coin（付费货币）        │
│              ↓ 消费               │
│    ┌───┬───┬───┬───┐            │
│    │礼物│外观│能力│市场│           │
│    └───┴───┴───┴───┘            │
└─────────────────────────────────┘

┌─────────────────────────────────┐
│      Experience Point（XP）      │
│         （免费成长积分）           │
│              ↓ 累积               │
│    ┌───┬───┬───┐                │
│    │等级│关系│解锁│               │
│    └───┴───┴───┘                │
└─────────────────────────────────┘
```

### 3.2 Life Coin（付费货币）

| 属性 | 说明 |
|------|------|
| **获取方式** | 真实货币充值 |
| **汇率** | 1 元 = 10 Life Coin |
| **用途** | 礼物、外观、能力解锁、Marketplace 购买 |
| **可赠送** | 用户之间可赠送 Life Coin |
| **可退款** | 未消费的 Life Coin可退款（有条件） |
| **过期** | 永不过期 |

### 3.3 Experience Point（成长积分）

| 属性 | 说明 |
|------|------|
| **获取方式** | 互动、签到、完成任务、被点赞 |
| **用途** | 用户等级、关系等级、解锁免费内容 |
| **不可交易** | XP 不能转移、不能购买 |
| **过期** | 永不过期 |
| **与 Life Coin 关系** | 独立系统，互不影响 |

### 3.4 消费场景

| 场景 | 货币 | 说明 |
|------|------|------|
| 礼物打赏 | Life Coin | 给数字生命或创作者送礼物 |
| 外观购买 | Life Coin | Live2D 皮肤、头像框、特效 |
| 能力解锁 | Life Coin | 高级技能、特殊能力 |
| Marketplace 购买 | Life Coin | 购买数字生命模板、插件 |
| 等级提升 | XP | 自动累积，解锁免费权益 |
| 关系阶段 | XP | 与数字生命的关系成长 |

## 四、Digital Life Package（数字生命资产包）

### 4.1 概念

Marketplace 交易的核心单元是 **Digital Life Package**——一个完整的数字生命资产包。

```
Digital Life Package
├── 人格（Personality）
│   └── 五维模型 + 说话风格 + 背景故事
├── 记忆（Memory）
│   └── 预设记忆模板（可选）
├── 技能（Skills）
│   └── 特殊能力 / 知识领域
├── 外观（Appearance）
│   └── Live2D / VRM / Spine 模型
└── 声音（Voice）
    └── TTS 语音模型配置
```

### 4.2 资产类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **完整数字生命** | 包含全部五要素 | "治愈系姐姐"完整包 |
| **人格模板** | 仅人格设定 | "傲娇少女"人格 |
| **外观资源** | 仅视觉资产 | Live2D 模型 / VRM 模型 |
| **插件** | 扩展能力 | 翻译插件 / 绘画插件 |
| **声音包** | TTS 配置 | "温柔女声"语音包 |

## 五、经济循环模型

### 5.1 货币流转

```
用户充值
    ↓
Life Coin 进入用户钱包
    ↓
消费场景
    ├─ 礼物 → 数字生命 / 创作者
    │   └─ 70% 收件人 / 30% 平台
    ├─ 外观 → 平台
    │   └─ 100% 平台（或与创作者分成）
    ├─ Marketplace → 创作者
    │   └─ 70% 创作者 / 30% 平台
    └─ 能力解锁 → 平台
        └─ 100% 平台
    ↓
创作者收益 → 提现
    └─ 平台抽成后，创作者可提现
```

### 5.2 经济健康指标

| 指标 | 说明 | 健康范围 |
|------|------|---------|
| ARPU | 每用户平均收入 | > ¥15/月 |
| 付费率 | 付费用户占比 | > 5% |
| Creator 活跃率 | 活跃创作者占比 | > 10% |
| Marketplace GMV | 市场交易总额 | 持续增长 |
| 货币流通速度 | Life Coin 周转率 | 0.5~2 次/月 |

## 六、系统架构

### 6.1 商业化系统组成

```
商业化系统
├── Subscription Domain（会员订阅）
│   ├── 订阅管理
│   ├── 权益管理
│   └── 续费/降级
├── Wallet & Asset Domain（钱包与资产）
│   ├── Life Coin 管理
│   ├── XP 管理
│   ├── 钱包账户
│   ├── 交易记录
│   └── 资产持有
├── Marketplace Domain（市场）
│   ├── 商品发布
│   ├── 交易撮合
│   ├── 分成结算
│   └── 评价系统
└── Payment Gateway（支付网关）
    ├── 充值
    ├── 提现
    └── 对账
```

### 6.2 与其他 Domain 的关系

```
商业化系统
    ▲
    │ 查询权益/余额
    │
    ├─ Digital Life — 检查订阅状态/互动限制
    ├─ Memory — 检查记忆容量限制
    ├─ Emotion — 检查情绪系统权限
    ├─ Community — 检查发帖权限/打赏
    └─ Narrative — 检查高级叙事权限

    │
    │ 发出事件
    ▼
    ├─ subscription.activated → 解锁权益
    ├─ wallet.charged → 充值成功
    ├─ wallet.spent → 消费成功
    ├─ marketplace.purchased → 资产转移
    └─ xp.earned → 积分增加
```

## 七、安全与合规

### 7.1 交易安全

| 风险 | 防范措施 |
|------|---------|
| 刷单 | 频率限制 + 异常检测 |
| 洗钱 | 大额交易审核 + KYC |
| 盗刷 | 支付密码 + 二次验证 |
| 退款滥用 | 退款条件限制 + 风控评分 |

### 7.2 合规要求

- **支付牌照**：通过持牌支付机构处理资金
- **虚拟货币合规**：Life Coin 不等同于法定货币，不可反向兑换（除退款外）
- **未成年人保护**：充值限额 + 实名认证
- **税务**：创作者收益代扣代缴个税
- **数据安全**：交易数据加密存储，PCI DSS 合规
